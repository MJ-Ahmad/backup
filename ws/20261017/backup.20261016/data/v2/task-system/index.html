হেল্প

কার্ড কীভাবে পড়বেন

  • TASK ID — টাস্কের স্বতন্ত্র নম্বর (যেমন TASK-000001)।
  • REG ID — রেজিস্ট্রি নম্বর, যা রেজিস্ট্রিতে টাস্কের অবস্থান নির্দেশ করে।
  • ঢাকা / UTC — টাস্ক তৈরির সময়; প্রতিটি ধাপের সমাপ্তির সময়ও দুই সময়ে লেখা থাকে।
  • সম্পূর্ণ রেকর্ড — বিবরণ, নোট, ধাপ, সংযুক্তি ও কার্যক্রম ইতিহাস দেখায়।

ডেটা কোথা থেকে আসে

এই ড্যাশবোর্ড সরাসরি data.json থেকে পড়ে এবং প্রতি ৩০ সেকেন্ডে নতুন করে লোড হয়। ডেটা বদলাতে শুধু CLI ব্যবহার করুন।

সমস্যা হলে

পেজ খালি বা "ডেটা লোড হয়নি" দেখালে ফাইলটি সরাসরি না খুলে ./run.sh web দিয়ে চালান।

CLI কমান্ড

নতুন টাস্ক

./run.sh task "শিরোনাম" "বিবরণ" --steps "ধাপ ১, ধাপ ২"

ধাপ সম্পন্ন (টাইমস্ট্যাম্পসহ)

./run.sh track TASK-000001 1

টাস্ক সম্পন্ন ও আর্কাইভ

./run.sh complete TASK-000001

ডেটাবেস যাচাই

./run.sh validate

ড্যাশবোর্ড চালু

./run.sh web

মোবাইলে দেখতে: BIND=0.0.0.0 ./run.sh web
